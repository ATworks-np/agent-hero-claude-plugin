# Agent Hero

Claude Code のプロンプトの上に勇者が住みつき、ダンジョンを勝手に潜っていく放置型 RPG のプラグインです。勇者を強くする資源は、Claude Code で使ったトークンです。普段どおりに作業するほど勇者が育ち、深い階まで進めるようになります。

```
█████ ███░░ ░░░░░  B12F 3/5 .....@.g....g....g....+
T2ゴブリン 18/40  PWR 12.4K HP ████░░ 1.2K memory
```

English is available too. Switch the language in the Settings tab.

## 遊び方の流れ

はじめてインストールしたときは、まだ冒険は始まっていません。帯に「/agent-hero を入力して冒険を始めてください」と出るので、`/agent-hero` でペインを開いて言語を選び、利用規約 (開発版の注意、このプラグインが読み取る情報、ライセンス) を読んで「利用規約に同意して始める」を押してください。そこから勇者が動き始めます。始める前に使ったトークンは数えません。

1. Claude Code で作業すると、使ったトークンが memory という資源になります。1,000 トークンで 1 memory です。キャッシュ読み込みのトークンは量が多いので、1/10 に割り引いて数えます。
2. 勇者はプロンプト上の帯で、0.5 秒に 1 歩ずつダンジョンを進みます。プレイヤーは操作しません。
3. `/agent-hero` でペインを開き、貯まった memory で勇者を強化します。
4. 強くなるほど深い階まで進め、ボスを倒すと良い装備や遺物が手に入ります。

勇者が動くのは、Claude Code のセッションを開いている間だけです。

## インストール

Claude Code のプロンプトで次の 1 行を実行してください。

```
/plugin install agent-hero --marketplace ATworks-np/agent-hero-claude-plugin
```

マーケットプレイスを追加するか聞かれたら `y` と答え、インストール先のスコープを選びます。ユーザースコープを選ぶと、すべてのプロジェクトで勇者が動きます。インストールが終わると、そのセッションですぐに動き始めます。

新しい版が出ると、帯の 3 行目とペインの上に「アップデートがあります」と、更新のしかたが出ます。版の確認は 6 時間に 1 回、GitHub の `plugin.json` を読んで行います。更新は次の順に実行します。手順は設定タブにも出ています。

```
! claude plugin update agent-hero
/reload-plugins
```

進行は設定フォルダの `agent-hero/` (既定では `~/.claude/agent-hero/`) に保存するので、更新や入れ直しでは消えません。

関数フック (function hooks) 形式のプラグインに対応した Claude Code が必要です。

## 画面

### 帯 (プロンプトの上の 2 行)

1 行目には、セットしたスキルの待ち時間、今いる階と部屋、ダンジョンの通路が並びます。待ち時間は 5 マスのバーで表し、満タンになると使える状態です。通路の `@` が勇者、英小文字が敵です。右端の `+` は次の部屋への扉、`>` は下り階段です。

2 行目には、戦っている敵の名前と HP、PWR、勇者の HP、手持ちの memory が出ます。PWR は強化に使った memory の累計です。

### ペイン (`/agent-hero`)

タブはクリックで切り替えます。強化やスキルに使える memory・SP が貯まっていると、そのタブに `●` が付きます。

| タブ | できること |
|---|---|
| ステータス | 攻撃力・防御力・HP と、強化の効果の合計を見る |
| 強化 | memory を払ってノードを取る |
| スキル | スキルを習得・強化し、3 つまでセットする |
| 遺物 | ボスが落とした遺物を付け外しする |
| 装備 | 武器と防具を鍛錬して品質を上げる |
| インベントリ | 拾った装備を持ち替える、まとめて分解する |
| 記録 | これまでの出来事を見る |
| マップ | 周回する階を選ぶ |
| 設定 | 言語、通知、バージョンと更新の手順、利用規約、セーブデータのリセット |

設定タブは、上に並んだ項目を選ぶと、その項目の中身が出ます。通知は種類 (新しい階、ボス、倒されたとき、装備と遺物、鍛錬、アップデート) ごとに、チェックを付け外しして出す・出さないを選べます。「すべてオン」「すべてオフ」でまとめて切り替えることもできます。初期値はアップデートだけオンで、ほかはオフです。

強化・スキル・マップの画面は、盤面をクリックするとキーで操作できます。

| 画面 | キー |
|---|---|
| 強化 | 矢印でノードを移動、Enter で取得または Lv 上げ、Backspace で払い戻し |
| スキル | 矢印でスキルを移動、Enter で習得・セット・外す、`u` で強化、Backspace で戻す |
| マップ | 矢印で階を選択、Enter でその階を周回、`a` で自動攻略に戻す |

## ゲームの仕組み

### ダンジョン

10 階で 1 Tier です。各階は 5 部屋が続き、1 部屋に敵が 4 体います。10 階ごとの階はボスの部屋 1 つだけです。敵の顔ぶれは階ごとに決まっていて、何度来ても同じ敵が同じ位置にいます。

倒されると、その階の 1 部屋目からやり直しです。階段を降りると HP が全回復します。

### 強化

強化は T1〜T10 の 10 ページあるツリーで、起点からつながったノードを memory で取っていきます。ノードの費用は、そのページで取った数が増えるほど上がります。

- 小ノード (`o`) は Lv5 まで上げられます。
- 主要ノード (`O`) は、常に効く特殊な効果を持ちます。
- キーストーン (`X`) は大きな効果と引き換えに弱点も持ち、1 ページに 1 つしか取れません。キーストーンを取ると次のページが開きます。
- 各ページの起点 (`S`) には、取得しなくても効く効果があります。T1 の起点は最大 HP +50・攻撃力 +5・防御力 +5、T2 以降の起点はトークン倍率 ×2 です。ページが 1 つ開くごとに、トークンから得る memory が 2 倍になります。

取ったノードは Backspace で払い戻せ、払った memory が戻ります。

### スキル

スキルは戦闘中に勇者が自動で使う技です。強化ツリーの SP ノードを取るとスキルポイント (SP) が増え、SP でスキルを習得・強化します。習得はいくつでもできますが、戦闘で使われるのはセットした 3 つだけです。

### 装備

敵はまれに武器か防具を落とします。品質はコモンからアルティメットまで 10 段階あり、今の装備より強ければ自動で持ち替えます。

鍛錬は memory を払って品質を 1 段上げる操作で、必ず成功します。いらない装備は分解すると memory になります。

### 遺物

遺物はボスがまれに落とす装飾品で、ランダムな付与効果が付いています。トークン倍率やスキルポイントが上がるものもあります。付けられる数は、開いた強化ページの数 − 1 です。

### マップ

到達した階は、いつでも選んで周回できます。装備や遺物を集めたいときは、ボスの階を周回すると効率が上がります。`a` を押すと、一番深い階から先へ進む自動攻略に戻ります。

## 複数のセッション

勇者は 1 人で、Claude Code のどのセッションでも同じ勇者が冒険しています。どのセッションで使ったトークンも合算されます。強化などの操作は、どのセッションから行っても全セッションに反映されます。

## 読み取る情報

このプラグインが Claude Code から読み取るのは、モデルの応答ごとのトークン数 (入力・出力・キャッシュ) と、ターンの開始と終了だけです。プロンプト、会話の内容、コード、ファイルの中身、ツールの実行内容は読み取りません。

進行は `~/.claude/agent-hero/` に保存します。読み取った情報も進行も、外部へは一切送信しません。通信は、6 時間に 1 回 GitHub からこのリポジトリの `plugin.json` を受信し、新しい版があるか確かめるときだけです。この内容は、設定タブの「利用規約」でも確認できます。

## 調整する

数値と文言はコードから分けて、次のファイルに置いています。

| ファイル | 中身 |
|---|---|
| `config/balance.ts` | ゲームバランスの数値 (敵の強さ、費用、ドロップ率、スキルの効果量など) |
| `config/content.ts` | 名前と説明文 (ダンジョン、敵、装備、ノード、スキル)。英語版も同じファイルにある |
| `config/text.ts` | 画面と記録の文言 (日本語と英語) |

`tools/simulate.sh` は、毎日の使用トークンから「何日目にどこまで進むか」を試算するツールです。`--set` を付けると、`config/balance.ts` の値を書き換えずに試せます。実行には Node.js と TypeScript (`tsc`) が必要です。

```sh
tools/simulate.sh --tokens 13000000 --hours 6 --days 30
tools/simulate.sh --days 30 --set monster.hpGrowth=10
```

テストは `claude plugin test .` で実行します。

手元で改造しながら遊ぶときは、clone したフォルダを `claude --plugin-dir <フォルダ>` で読み込んでください。マーケットプレイスから入れた版と同時に読み込むと勇者が二重に動くので、先に `claude plugin uninstall agent-hero` で外しておきます。
